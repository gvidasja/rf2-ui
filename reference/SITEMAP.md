# Stock UI site map

Generated by `bun reference/dump.ts`. Every ui-router state of the stock UI, grouped by the page (CEF document)
that hosts it. URLs are hash routes (`/start/index.html#<url>`); the stock start page is reachable as
`/start/stock.html#<url>` while our bundle is installed. Template/component links point into `stock/` (gitignored, run the dump).

The game switches pages itself based on `GET /navigation/state` → `state.navigationState`; the stock JS only reads it
(`framework/services/NavigationService`). Abstract states are layouts (tabs/frames) for their children.
81 screens (94 states including layouts). Screenshots: `bun reference/screenshots.ts [--app event] [--window]` (gitignored);
"in game" = real game-window capture (3D + UI composited), see [UI_SHELL.md](UI_SHELL.md).
