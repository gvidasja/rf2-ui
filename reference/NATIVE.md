# Native API (`rFactor2.exe` via JNI)

Generated by `bun reference/dump.ts`. Every `native` method in `Bin/rFactor2.jar` (`net.rfactor2.jni.*`).
Java services (`net.rfactor2.<area>.<X>Service`, OSGi) wrap them in commands queued onto the game thread;
a bundle can depend on those services (see `bundle/` in this repo). The UI reaches them through REST endpoints
and through the websocket channel `/ui` (topics pushed to the page); a few are only used by other bundles.
Natives reached from nowhere are capabilities nothing uses today — candidates for new endpoints.

232 natives: 204 reachable from REST, 7 only through websocket topics or other bundles, **21 unused**.
