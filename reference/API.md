# rFactor 2 REST API — contracts

Generated by `bun reference/dump.ts` from the game's Java classes. Types are TypeScript, as defined in
[`rf2-api.ts`](rf2-api.ts) (`Endpoints` maps `"METHOD /path"` → params/body/response). Natives: see [NATIVE.md](NATIVE.md).

- JSON follows Jackson's defaults: public getters (`getFoo` → `foo`, `isFoo` → `foo`) and public fields; nulls are omitted.
- Enums serialize as their constant names; `Map<Enum, V>` becomes an object keyed by constant name.
- A body param of type `string` is sent raw (not JSON); most `POST`s without `Consumes` take `text/plain`.
- Every call into the game runs on the game thread via a command queue (`net.rfactor2.jni.Queue`).
- 265 endpoints in 20 groups. Live samples: 83 (`generated/samples/`, gitignored).
